
# Sensitive reports

Do not publish original game files, saves, account data, tokens or unredacted private paths in an issue. If a defect could expose such data or escape the selected import directory, use the repository's private vulnerability-reporting channel if available. Otherwise open a minimal issue requesting a private contact route, without posting the sensitive details.

The importer validates directory bounds, names, supported executable identity and destination containment. These checks must not be removed to accept another revision. Releases are experimental and unsigned. Verify the published SHA-256 checksums and download from this project's release page.
