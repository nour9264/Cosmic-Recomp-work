# Cosmic Recomp

## Alpha 8.2 — Mouse Menus, Music Integration & Modern Button Icons

- **Mouse in menus:** an Omnitrix cursor replaces the Windows pointer in menus and turns red in Play as Albedo mode. Hover and click work in the stock menus, the pause menu, the Options pages, Level Select and the Upgrades wheel. The R3 form wheel supports hover.
- **Keyboard and Mouse:** the "Keyboard" button icon option is renamed "Keyboard and Mouse". Prompts show keycap and mouse images for your current bindings. The Controls page now has one custom profile, with **Restore defaults**.
- **PC mouse camera:** the camera turns with mouse movement like a PC game, independent of frame rate, with adjustable sensitivity and no speed cap.
- **Smart Music Integration:** detects Spotify and other players through Windows media controls. Press **M** or **View / Share** during gameplay to open the music overlay. It shows title, artist, album art and progress, with Previous (LB / L1 / Q), Play-Pause (X / Square / Space), Next (RB / R1 / E) and Close (View / Share / M). The game keeps running while it is open, and its input does not reach the game.
- **Audio ducking:** while music plays, the game audio fades down smoothly and fades back after the music stops. Set the amount with **Music priority** in the music overlay (0% = off). Windows and Spotify volumes are never changed.
- **Sound settings:** the in-game Sound page adds Music Integration. The launcher has a new **Sound** tab with Music, SFX and Voice volume and Music Integration.
- **Modern button icons:** new Xbox and PlayStation face, bumper, trigger and stick icons in the stock menus, HUD prompts, QTEs and text prompts. Auto follows the connected controller.
- **Options badge:** the Options pages show the original Omnitrix badge again. The launcher extracts it from your game files, with a red version for Albedo mode.

**Work in progress:** Field of View. The slider exists in the launcher and in-game Gameplay settings, but it does not change the gameplay view yet. Leave it at 0.

**Known issues:** the music overlay cannot show song titles in non-Latin scripts. Ultrawide is not supported.

For an Alpha 8.2 build, compile both launcher bridges with `--hero-time --gpu-diagnostics --performance-alpha5 --ultimate-voices --discord-presence`, adding `--four-arms` for the optional bridge. Install the SDK with the updated `sdk-patches/rex-sdk-local.diff`. The button icon resources are generated by `tools/build_modern_button_icons.cs` and `tools/build_keyboard_prompt_sprites.cs`.

## Alpha 4 - Stability & Performance (upstream)

Cosmic Recomp is an experimental Windows 10/11 x64 native port of **Ben 10 Ultimate Alien: Cosmic Destruction** (Xbox 360), built on ReXGlue (0.10.0 series) and Direct3D 12. **Bring your own copy:** no ISO, game files, generated game code or saves are distributed.

- **Wipe Data:** archives this game's profile to `game-data/save-backups` and returns to the launcher.

## Keyboard and controllers

Controllers are supported natively through the SDK SDL backend, including XInput-compatible controllers. Button icons can be set to Xbox, PlayStation, Keyboard and Mouse, or Auto under Options → Video. Contextual actions follow the original game.

| Keyboard | Xbox input / purpose |
| --- | --- |
| WASD | Left stick: movement |
| Arrows | Right stick: camera |
| Space or semicolon | A: confirm / jump |
| Backspace or apostrophe | B: back / original B action |
| L / P | X / Y |
| Q or I | LT: alien wheel |
| E or O | RT: abilities; next wheel page while LT held with All Aliens ON |
| 1 / 3 | LB / RB |
| F / K | Left / right stick click |
| Shift + arrows | D-pad |
| Enter or X | Start / pause |
| Tab or Z | Back / Select |

With All Aliens ON, hold Q and tap E to cycle pages. The mouse turns the camera during gameplay and points and clicks in menus. Rebind keys under **Options → Gameplay → Customize Keyboard and Mouse Controls** or in the launcher. Mappings checked against the SDK keyboard driver and launcher configuration; not every contextual keyboard action has been playtested.

## Getting started

1. Run the installer and choose your installation folder on any writable drive. To update, select the existing CosmicRecomp folder.
2. In Settings, choose **Select ISO**, wait for validation, then **Prepare game**.
3. Click **Play**. The default is native 720p with a 30 FPS limit. Higher limits remain experimental.
4. Preserve `CosmicRecomp/game-data/user` when updating. Setup logs are in `CosmicRecomp/logs`; game/startup logs are in `CosmicRecomp/game-data/logs`.

Save/Continue was manually confirmed in an earlier test. No saves are supplied. Use a separate folder for a new test release and preserve your existing user folder before migration.
